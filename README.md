 AppMaui Jogo da Velha

Um simples e divertido jogo da velha (tic-tac-toe) desenvolvido com **.NET MAUI**, focado em aprendizado, prática de interface responsiva e navegação entre páginas.

 🧩 Funcionalidades

- Interface intuitiva com grade 3x3 para o jogo.
- Dois jogadores locais (X e O) alternam entre as jogadas.
- Verificação automática de vitória ou empate.
- Exibição de mensagem personalizada na tela de vitória (`VictoryPage`).
- Lógica limpa e modular com boa separação entre UI e regras.

📱 Tecnologias Utilizadas

- [.NET MAUI](https://learn.microsoft.com/dotnet/maui/)
- C# (Code-behind)
- XAML para design de interface
